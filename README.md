# Dairy Dashboard

A dashboard for dairy products from brands such as Amul, Britannia Industries and Dodla Dairy. I first designed and built the database in SQL, then connected it to Power BI to create the dashboard. It has two pages: Product Performance and Farm & Logistics.

## The problem
Dairy products expire quickly, so a business has to track what it makes, what it sells and how much value that adds up to over time. I built this to bring value, quantity and price together.

## How it was built
1. Created the dairy database in SQL (products, brands, quantities, prices, production and expiration dates).
2. Connected Power BI to the SQL database.
3. Built the measures, charts and filters on top of it.

## What you can explore
- Total value (118.19M), quantity (2.17M litres or kg) and average price per unit (54.79)
- Total value by month and by year
- Total value by product (Lassi, Curd, Cheese, Butter, Ghee, Ice Cream, Milk, Paneer, Yogurt, Buttermilk)
- A table with production and expiration dates
- Brand and product filters

## What I found
In the Amul view, Lassi, Curd and Cheese bring in the most value (about 3.2M to 3.4M each), with Butter close behind. Monthly value moves up and down within a fairly narrow band through the year.

## Tools
SQL and Power BI
